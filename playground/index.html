      Use citesync in your repository
      

      Keep citation files in sync as your project changes.
      

      




      

      Run with uv from your repository. Review changes before committing.
      uvx citesync init    # create CITATION.cff if you do not have one
uvx citesync write   # update the other citation files
uvx citesync check   # check that the files agree
      

      Add to .pre-commit-config.yaml, then run prek install or pre-commit install.
      repos:
  - repo: https://github.com/simonvanlierde/citesync
    rev: v0.4.0
    hooks:
      - id: citesync
      

      Add these steps to a GitHub Actions job running on ubuntu-latest with your citation files committed.
      steps:
  - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
  - uses: astral-sh/setup-uv@1c37ad07a6a961277cf70c0d37d6f313000f5884 # v10.3.0
  - run: uvx --from citesync==0.4.0 citesync check
